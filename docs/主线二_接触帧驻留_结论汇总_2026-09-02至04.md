## 0. 一句话

**arc 生成成功率低的载体是接触瞬间的水平位置：MimicGen 按源演示的帧号重放，把人"停稳再动夹爪"
这一步丢掉了。在每次夹爪指令前插入无噪声驻留、停在序列里现成的名义目标上，原版 MimicGen 从 32%
提到 55%，arc 1.2cm 从 34% 提到 50%，arc 3.0cm 从 16% 提到 41~50%。幅度再往上（5~10cm）
产出陡降，损失全在搬运段，拉长时间救不回。**

## 1. 机制：为什么 arc 伤成功率，为什么 MimicGen 自己也只有 32%

1. **源演示里人是停下来等臂到位再动夹爪的。** 10 条演示逐帧量：普通帧目标−实际中位 4.86cm
   （指令比执行快，91% 的帧 >0.3cm），夹爪动作那一帧中位 **0.00cm**（70% <0.3cm）。存下来的
   `target_eef_pose` 就是 `eef_pos + action[:3]`（核对误差 0.0000cm），"人停了"是记录不是推断。
2. **MimicGen 按帧号重放目标序列，夹爪指令也按帧号下达。** 生成的手臂因为每步 3cm/轴的动作噪声
   和不同的关节构型，到达接触帧时还在以 1.7cm/5 帧赶路（人是 1.14，驻留后 0.64），闭合时离方块
   1.12cm（人 0.56cm）。
3. **arc 在此之上再加一份系统偏移**：3.0cm 时进入冻结段还剩约 45% 幅度，接触帧闭合距离
   1.42cm。抓取失败的样本在尾部（夹爪位置偏差 1.88cm 对成功的 0.72cm，d=1.35）；放置失败的
   样本释放时方块相对下方方块偏 2.22cm，正压在 2.34cm 的翻倒阈值上。
4. **两个来源走同一条通道，驻留一起压下去。**

## 2. 驻留：数字

| 条件 | 成功率 | 释放帧方块偏移 中位/p90 |
|---|---|---|
| MimicGen 0.5cm，不驻留（= 原版行为） | 32.3% | 1.37 / 4.68 cm |
| + 固定驻留 20 帧 | 50.3%（换一串场景 55.3%） | 0.92 / 1.70 |
| + **门控驻留**（进 0.3cm 或 ≤40 帧） | **55.0%** | 0.85 / 1.57 |
| 0cm（无 arc）+ 门控 | 51.5% | 0.87 / 1.75 |
| arc 1.2cm（生产工作点）+ 驻留 / 门控 | **50.0% / 51.7%**（v1 生产时 34.1%） | 0.91 / 1.78 |
| arc 3.0cm 冻结 30%，不驻留 | 15.7% | 2.01 / 9.54 |
| + 固定驻留 / 门控 | 39.0%（换场景 40.3%）/ 44.0% | 1.17 / 5.34 |
| arc 3.0cm **冻结 50%** + 驻留 | **49.7%**（与无 arc 持平） | 0.93 / 1.73 |

- 机制核验都对上了：驻留组 episode 长 30~35%（4 × 20 帧）；闭合帧到方块距离从 1.12~1.42 退到
  0.84cm（人 0.56）；抄平行 MimicGen 实际位姿的 `arc_snap` 只有 19.7%——平行组自己只成功 32%、
  接触时就离方块 1.12cm，抄它等于抄它的噪声误差。
- 驻留作用在**放置**（51.7 → 69.7%）和**第二次抓取**（条件成功 75 → 91%），第一次抓取本来就
  95~99%。
- 门控比固定帧数再高约 5pp、平均帧数相当（17.8~19.5）；五分之一的驻留到上限仍没进 0.3cm——
  不是慢（上限 40 → 60 没变化），是物理上到不了（释放时目标被下方方块顶住）。**门控判据以后应改
  成"手臂停住即放行"或按事件分阈值。**

## 3. 幅度：手臂只走出指令的四到五成，大幅度死在搬运段

用每段存下来的指令路径量**实际**弧线（`effective_amplitude.py`，到未扰动路径的空间距离减去到扰动
路径的距离，0cm 时恒为 0）：

| 名义 | 指令峰值 | 实际峰值 中位/p90 | 实际/指令 | 方块2 放上 | 成功率（门控） |
|---|---|---|---|---|---|
| 1.2cm | 1.16 | 0.59 / 1.03 | 0.51 | 69.3% | 51.7% |
| 3.0cm | 2.79 | 1.24 / 2.36 | 0.45 | 61.3% | 41.0% |
| 5cm | 4.35 | 1.88 / 3.52 | 0.43 | 46.0% | 26.0% |
| 8cm | 6.87 | 2.86 / 5.32 | 0.42 | 27.0% | 9.7% |
| 10cm | 8.34 | 3.49 / 6.62 | 0.42 | 16.3% | 6.0% |

- **原因在控制链**：动作 = 目标 − 当前 + 噪声，乘 `scale=0.5`，DLS IK 转关节目标，PD（刚度 400、
  阻尼 80）在 50ms 内只实现一部分——每帧沿误差方向走约 0.11×误差，是**时间常数约 10 帧的一阶
  跟踪器**，四十帧内起落的鼓包被削到四五成，跟幅度无关。关节限位、关节速度限位都不是原因（数据
  里不贴边）；不是奇异姿态（径向/切向差别小）；**竖直方向的鼓包跟得最差**（0.25 对水平 0.45）。
- **拉长时间（自由段 ×2）不行**：手臂多追上了（0.38 → 0.59，符合一阶模型对 80 帧鼓包的预测），
  但进冻结段时离标称路径更远、18 帧尾巴 + 门控拉不回来（5cm 接触残差 0.64 → 1.03cm），方块偏心
  更大（1.20 → 1.75cm），产出 5cm 26.0 → 22.3%、10cm 6.0 → 4.3%。0cm 拉长 52.7%，"慢"本身无害。
- **所以 3cm 以上的限制不是"跟不上"，是"跟上了回不来"+"搬运时方块被甩歪"**：第一次抓取
  99.7 → 87.7%，"方块2 放到方块1 上" 71 → 16%，释放时方块偏心 0.86 → 2.84cm（10cm 时 p90
  13.5cm，方块已飞出）。

## 4. 用户定的设计原则（2026-09-04）

> 放宽时间让手臂追，但**不能让手臂在自由段真的追上目标点**——已经证明那会把它带到源演示没去过
> 的地方。手臂和目标点要保持**跟源演示一样的距离**（同样的滞后量）；只在接触段/放置段的**末端**
> 冻结目标点，再让手臂靠近。

这条原则跟数据一致：源演示里运动中目标领先 4.86cm、夹爪动作帧领先 0.00cm；驻留正是把"末端冻结
再靠近"补回来；"自由段追上目标"对应第五修法/提高增益那类失败。下一版机制要按它来定：自由段的
偏差允许存在（它是重放机制的一部分），只在冻结段末端收敛。

## 5. 当前推荐组合、适用范围、没测的

- **组合**：自由段 arc（峰值 ≤3cm；3cm 用冻结 50%，1.2cm 用冻结 30%）+ 每次夹爪指令前门控驻留
  （0.3cm / ≤40 帧，无噪声）。预期产出 50~55%，原版 32%。**报幅度报实际值**：1.2cm 名义 = 0.59cm
  实际，3.0cm = 1.24cm。
- **适用条件**：接触事件由夹爪指令标记（抓/放类）；源演示者在动夹爪前确实停了（这里 70%）。
  换"边走边夹"的演示要重测。
- **没测的**：只在接近段（夹爪空的 subtask 0、2）加大幅度——大幅度的损失全在搬运段，训练想要
  的"接近路径不同"也只需要接近段（Group A 在 3cm 无驻留下只扰 subtask 0 是 33.3% 对 22.0%）；
  只用水平方向；大幅度配更长冻结尾巴；门控保护下重试更高 `scale`；门控 + 冻结 50% 同用；训练侧
  影响（驻留让 episode 长 30~35%，策略会学到"接触前停顿"）。

## 6. patch 线索（等后续做）

官方 `SubTaskConfig.num_fixed_steps` 就是无噪声驻留，但放在每个 subtask **开头**，Franka stack 全部
配置设 0。该加的是"夹爪动作前驻留"（固定帧数或按收敛/停止门控）。证据：原版 32.3% → 55.0%，两串
场景复现。相关的另外两个已提 PR：#7433（`max_num_failures` 死配置）、#7434（`cubes_stacked` 空中
判定）。

## 7. 撤回的旧结论

- 2.11"载体三候选全排除、接触时手臂位置不是载体"——第三/第五修法的驻留都在夹爪动完 11~23 帧后
  （信号同帧触发 + 1 帧 + offset 10~20），从没在接触帧收敛过；0.69cm 是成功样本中位数。
- 2.10"5cm 落后是重放机制的一部分，任何追上目标的修法都是推离源演示"——对运动过程成立，对
  接触帧不成立（那一帧目标 = 实际）。
- 2.13"方向二未公平测试，原因是滞后"——主因是修正量用了 subtask 最后一帧（接触后 11~23 帧，
  手臂已走 10~17cm）；修正后到参照距离 0.69 → 0.36cm，结果 19.7%，抄平行组本身是错的参照。
- "MimicGen 自带 3cm 噪声让基线贴着阈值"这条推测被 `ref_hold`（32.3 → 50.3%）坐实。
- "鼓包太快不是太大"（09-04 上午）——拉长实验推翻：跟得越好回得越难。

## 8. 推理陷阱（新增三条，编号接思维链交接第六节）

11. 干预对准的是"事件"还是"subtask 边界"，先量两者差几帧。
12. 一个量的全局中位数不是它在关键帧上的值，关键帧单独量。
13. 把给控制器的量当成控制器做到的量（峰值当平均、目标当实际、指令当实际，三次）。
