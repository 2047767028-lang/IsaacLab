# 家具装配资产来源调研（2026-09-03）

> 任务：为主线一的家具装配 benchmark 调研"可拆分 3D 家具资产从哪来"。
> 事实来源：GitHub API / raw 文件直取、官方项目页、arXiv 原文。许可条款以各自 LICENSE 为准。

## 0. 核心判断：**"拆分" ≠ "能装配"**

这是整个调研最重要的结论，也是选型的分水岭：

- **语义零件拆分**（PartNet 那类）：椅子 = 椅背 + 椅座 + 椅腿。**装不回去**——
  零件之间没有榫卯、销孔、螺纹的几何，切开的断面是任意的。
- **装配件拆分**（FurnitureBench / IKEA-Manual 那类）：零件是**按真实装配单元**分的，
  带配合特征（FurnitureBench 甚至单独建了 `chair_nut1` / `chair_nut2` 螺母）。

**benchmark 只能用后者。** 前者数量再大（PartNet 57 万零件）也没用。

## 1. 梯队 1：现在就能用，许可干净

### FurnitureBench 资产（**MIT**，推荐作为第一批）
仓库 `clvrai/furniture-bench`，LICENSE 确认为 **MIT**（Copyright 2023 CLVR lab @ KAIST）。
`furniture_bench/assets/furniture/` 下共 345 个文件：

| 格式 | 数量 |

| `.obj` | 40 |

| lamp | `lamp_base` `lamp_bulb` `lamp_hood` |
| 场景 | `background` `obstacle1..3` `obstacle_front` `obstacle_side` `base_tag` |

约 **9 件家具**。对应 FurnitureBench 论文里的 3 个任务
（one-leg table 4 步 / round table 8 步 / lamp 11 步）。

**Isaac Lab 自带转换器，URDF/OBJ → USD 直接可转**（本仓库已确认存在）：
- `scripts/tools/convert_urdf.py`、`scripts/tools/convert_mesh.py`
- 模块：`source/isaaclab/isaaclab/sim/converters/{urdf,mesh,mjcf}_converter.py`

⚠️ **短板**：这些是 **3D 打印的玩具尺度**零件。正是 FurnitureVLA 论文批评的 "toy-scale"。
→ 结论：**拿来打通流水线是完美的第一批，但撑不起"真实尺度"这个卖点。**

## 2. 梯队 2：权威可用，但许可有传染性

### IKEA 官方 3D Assembly Dataset（`github.com/IKEA/IKEA3DAssemblyDataset`）
- 发布方：**Inter IKEA Systems B.V.**（IKEA 本家），2021。
- 内容：**仅 5 件** —— LACK 边桌 55×55 白 / EKET 柜 35×25×35 / EKET 带抽屉柜 70×35×35 /
  BEKVÄM 梯凳黑 / DALFRED 吧凳黑。
- 格式：**glTF/GLB**（含材质，单位米）+ **OBJ**（仅基础色，单位毫米）+ **装配说明书 PDF**。
- 许可：**CC BY-NC-SA 4.0**。
- ⚠️ **SA（相同方式共享）是真风险**：衍生作品必须同许可发布。如果 benchmark 资产库里混入这 5 件，
  整个发布可能被要求以 CC BY-NC-SA 发布。**建议：要么单独隔离成可选包，要么不用。**

### IKEA-Manual（Stanford VisCAM，[arXiv 2302.01881](https://arxiv.org/abs/2302.01881)）
- **102 个 IKEA 物体**，每个**已分解为与说明书对应的装配件**。
- 附带：**树状装配计划**（哪一步连接哪些零件）、**零件间连接关系标注**、
  说明书 2D 分割、**2D-3D 对应**、3D 零件上的关键点。
- 下载：`https://download.cs.stanford.edu/viscam/ikea_manual/dataset.zip`（直链）。
- **许可未知** —— 项目页没写，需要下载后看 zip 内 LICENSE。**这是下一步必须先确认的一条。**
- 评价：**"可拆分家具资产"里质量最高、规模最合适的一批**（102 件 vs FurnitureBench 9 件），
  而且连接关系标注正是装配 benchmark 要的。许可若干净，这是主力来源。

## 3. 梯队 3：规模大，但不满足装配需求

| 数据集 | 规模 | 问题 |
|---|---|---|
| **PartNet** | 26,671 模型 / 573,585 零件实例，含 Chair/Table/Cabinet | **语义分割级拆分，装不回去**；需申请审批；仅非商用；衍生再分发条款不明（继承 ShapeNet 条款） |
| **PartNet-Mobility** | 2,346 个带运动学标注物体（SAPIEN 用） | 是**铰接**（开门/拉抽屉），不是**装配** |
| **ABO**（Amazon Berkeley Objects） | 7,953 个艺术家建模网格 | 整体模型，非零件级；CC BY-NC 4.0 |
| **3D-FUTURE**（阿里） | 16.5K 家具模型，工业级细节纹理 | 整体模型，非零件级 |

## 4. 梯队 4：自建（团队人力应该投的地方）

学长计划里的 "Blender、codex、淘宝、团队工作"。这是唯一能同时满足
**真实尺度 + 可控连接件类型 + 许可完全自有** 的来源，也正是论文卖点所在。
淘宝路线（买实物 → 测量/扫描 → 建模）目前我做不了调研——需要浏览器（见 §6）。

## 5. 建议的资产策略

1. **第一批用 FurnitureBench（MIT）打通全流水线** —— 9 件家具、43 个 URDF，
   用 Isaac Lab 自带 `convert_urdf.py` 转 USD，零许可风险，零建模人力。
   目标：验证"Arena 任务定义 → IsaacTeleop 遥操作采集 → mimic 扩充 → 并行评测"整条链。
2. **同时确认 IKEA-Manual 的许可** —— 若可用，它的 102 件 + 连接关系标注是规模化的主力。
3. **真实尺度资产自建** —— 这是论文差异点，团队人力投这里。
   FurnitureBench 的玩具尺度不能直接放大：放大后连接件的配合公差、摩擦、重力效应全变，
   物理上不等价，必须重新设计配合特征。
4. **IKEA 官方 5 件谨慎使用** —— CC BY-NC-**SA** 的传染性，要么隔离要么不用。
