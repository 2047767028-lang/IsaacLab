主线二 · 第二层验证

扰动增广第二层验证

给 MimicGen 生成的轨迹加上接触锚定的弧线扰动，训出来的 pi0.5 策略会更强吗？ 三个数据集、五次训练、1500 次闭环 rollout 之后的答案，以及一个必须撤回的旧结论。

2026-08-29 Isaac Lab 2.3.2 · Isaac Sim 5.1 pi0.5 LoRA · openpi Stack-Cube-Franka-IK-Rel-Visuomotor

结论先说

修好训练配置之后，扰动增广数据既没测出害处，也没测出益处。 先前那个「有害 11.3 个百分点、p=0.001」的结论已撤回—— 它的真实来源是学习率配错导致的训练不收敛。真正有价值的产出是一条方法学结论： 单次训练的组间对比在这个任务上不可信。

01三组数据集的成绩

每组 n=300 闭环 rollout · Wilson 95% 置信区间 · 同 seed 配对

三个数据集各自训练 pi0.5 LoRA，再放回 Isaac Sim 跑闭环叠方块任务。 baseline 是 380 条干净的 MimicGen 演示；arc 是 358 条 全部加了 1.2cm 弧线扰动的演示；mixed 是 190 条干净 + 190 条扰动， 总量固定在 380 条以排除数据量这个混淆因素。

为了把「数据集的影响」和「训练本身的随机性」分开，baseline 和 arc 各训了 两个不同的训练种子。

02一个必须撤回的结论

学习率配错 · 静默失败 · 伪造出 p=0.001

已撤回

baseline 81.0% vs arc 69.7%，差 −11.3pp，McNemar p=0.0011 → 「扰动增广损害策略性能」

这个结论的两个数字都来自从未收敛的模型。它不是一个偏弱的证据， 而是一个方向和量级都不可信的伪发现。

病根在一行超参数。训练用的余弦退火调度写成了 peak_lr = 5e-5、decay_lr = 5e-5—— 起点和终点相同，等于全程恒定学习率，而且是 openpi 默认峰值的两倍、 没有 warmup。openpi 自己在日志里打过一行 this results in a constant schedule，当时没人注意。

右边两个数字是关键：训练内部的波动（22.5pp）是被当作结论的数据效应（11.3pp）的两倍。 直接测量 step 16000 与 19999 两个 checkpoint——同一次训练、同一批数据—— 闭环成功率是 58.5% 与 81.0%，置信区间完全不重叠。

怎么判断一次训练到底收敛没有

不要只看 loss 曲线。两个更硬的判据：

  • param_norm 分段增量是否逐段减速。 v1 的四个 5000 步窗口增量是 +1.208 / +1.204 / +1.193 / +1.195—— 第 20000 步的权重仍以第 0 步的速度在漂。修复后是 +0.149 / +0.111 / +0.043 / +0.010。
  • 末段 loss 斜率的 t 值是否已经 |t| < 2。 注意窗口要短：v2 的末 1000 步 t=+0.18（已走平），但拉到末 4000 步会算出 t=−17.4，因为混进了早期还在改进的阶段。

03噪声底线：这次实验的分辨率

同一批数据 · 只换训练种子 · 各 n=300

修好收敛之后，剩下的问题是：同样的数据重训一次，成绩会飘多少？ 没有这把尺子，任何「A 组比 B 组高几个百分点」的说法都无法判读。

  • baseline：70.67% → 67.00%，−3.67pp（p=0.359）
  • arc：65.33% → 68.67%，+3.33pp（p=0.440）

两个种子差异本身都不显著，所以严格的表述是 训练噪声 ≤ 约 4pp，而不是「已测得噪声为 3.5pp」。 这也意味着 −5.33pp 的数据集差异与噪声同量级，不能直接归因于数据。

等价性怎么说。 p 值不显著不等于没有差异。按 TOST 等价检验，本实验支持的结论是 「两组差异不超过 ±11.3pp」—— 只有当你认为 11pp 以内算「性能几乎一样」时，才能说它们等价。 要把这个界限收窄到 ±8pp，需要约 1485 次 rollout，是当前的 5 倍。

04为什么 arc 扰动没有效果

对 10 条源演示的直接度量 · 变换到物体坐标系以除掉物体位置的影响

设计这个方法时的前提是：arc 扰动本质上在模拟人类采集数据时的路径变化。 这个前提经实测不成立，而且差在最要紧的那一维——方向。

幅度上 arc 只有人类自然弯曲的 13%~25%。但真正的问题是方向： subtask 3 的 10 条人类演示全部向上，仰角 +47.2° ~ +67.0°， 方向合成长度 R=0.850（各向同性随机时 R 的中位数只有 0.285，经验 p<0.0001）。 而 arc 用的是 torch.randn(3) 归一化——各向同性随机方向， 约一半时间在往下扰动。

更根本的一点：人类那个向上的弧线不是「扰动」，它就是策略本身。 抬起来绕过去是完成任务的正确方式。而 MimicGen 是照搬源演示的路径形状再做位姿变换的， 所以这个抬升本来就完整保留在 baseline 数据里 （实测 144 条生成数据 98.6% 仍向上，仰角均值 +55.0°，对照源演示的 +58°）。 本实验真实的对照关系因此是「MimicGen 数据 vs MimicGen 数据 + 各向同性随机噪声」， 而不是「MimicGen vs 人类风格」。

05附带发现：MimicGen 的失败去哪了

1050 次生成尝试只有 36% 成功 · 此前无人分析

复现环境自带的 cubes_stacked 判据，并先在成功样本上验证 100% 通过 才拿去分类失败样本（第一版复现 0% 通过，暴露出两个坑：gripper_pos 观测里 第二根手指是取负存储的；成功判定要按「任意帧曾满足」而非「末帧满足」）。

其中 11% 是判据误杀，可以直接回收。 成功判据要求两根手指精确停在 0.0400、容差仅 ±0.104mm。这批样本停在 0.0387—— 差 1.2 毫米，但方块其实已经松开了。已验证成功样本能到达精确的 0.04000，所以这是 episode 提前结束的截断问题，不是稳态误差。 把容差放宽到 3mm 可回收其中 71%，生成产出约提升 5 个百分点。

主导的那 56% 则是真实的物理失败，而且判据阈值定得很准：末帧方块中心距呈明显双峰—— 1~2cm（叠上了）和 5~6cm（滑到旁边，约等于一个边长 4.68cm）， 而 3~4cm 这个「既没叠上也没滑开」的谷底全场只有 5/1050 例。 方块不可能半边悬空停住，4cm 的阈值正落在空谷里。

06方法学结论

可能比原问题本身更有价值

用「每组训练一次 + 评测 300 次」这种标准做法，在这个任务上无法分辨约 7pp 以内的数据集差异。 而绝大多数同类工作正是这么做的。三条证据构成完整链路：

  • 训练不收敛时，单次训练内部就能产生 22.5pp 的波动，足以伪造出 p=0.001 的显著结果；
  • 即使训练收敛，换个训练种子仍有 ±3~4pp 的波动；
  • 种子平均能把表观效应从 −5.33pp 压到 −1.83pp——差值的大部分本来就是噪声。

推论很直接：任何「A 组比 B 组好 X 个百分点」的结论，都应该先报噪声底线再报 X。 每组多个种子取平均不是锦上添花，是这类实验能不能成立的前提。

07尚未确认 · 下一步

如实标注不确定的部分

  • mixed 组只有一个训练种子。 它的 60.67% 相对 baseline 是 −10.00pp、p=0.0078，是全研究唯一统计显著的对比。 但已知种子波动有 ±3.7pp，单种子撑不住这个结论。 第二个种子（777）正在训练中，结论待确认。
  • 不能说「两组等价」。 置信区间 [−7.1, +3.5] 同时包含 0 和一个 7pp 的真实劣势。 本实验只能排除大于约 11pp 的效应。
  • 训练预算被压缩过。 受 12 小时窗口限制，v2 用的是 10000 步而非 20000 步（退火曲线同步压缩， 所以模型是收敛的，只是训练总量减半）。更长的训练是否改变结论，未测。
