## 当前状态一页（2026-09-04 深夜，峰值扫描后）

**我们在做什么**：给 MimicGen 生成的轨迹加"接触锚定"的弧线扰动（arc），目的是产出跟原版轨迹有明显
差异、又能真实完成任务的训练数据，供第二层验证（训 pi0.5 / DP / ACT，仿真测评）。

**已经确认的（可以直接拿去写）**
1. arc 伤成功率的载体是**闭合那一刻方块相对夹爪的位置**（抓取段的接近段），不在放置段、不在搬运段。
   偏心在闭合时就有（0cm 0.61 → 10cm 1.85cm），搬运中再滑只有 0.2~0.4cm 且不随幅度变，搬运段加速度
   各幅度完全一样（arc 被控制器滤平，加速度由动作噪声决定）。
2. MimicGen 按帧号重放，丢掉了人"停稳再动夹爪"这一步。在每次夹爪指令前门控驻留（进 0.3cm 或到上限，
   无噪声），原版 32.3% → 55.0%，两串场景复现。这是 patch 线索（官方 `num_fixed_steps` 放错了位置）。
3. 手臂只走出指令弧线的 42~51%（控制链是 `scale=0.5` × PD，10 帧时间常数的一阶跟踪器）；报幅度必须报
   **实际**值：1.2cm 名义 = 0.59 实际，3cm = 1.24，5cm = 1.5~1.9，10cm = 2.6~3.5。
4. **用户 09-04 的原则被证实**：扰动保留全轨迹、幅度不砍、手臂在自由段不追扰动目标、鼓包的返回在冻结段
   开始前几个时间常数结束、冻结段末端驻留再靠近。实现只动返回时机（v3 峰值位置 0.5 → 0.25）：
   5cm 26 → 48~51%，10cm 6 → 46.7%（配冻结 50%）/ 31.0%（冻结 30%），无扰动 51.5%，实际弧线不变。
5. 冻结比例和峰值提前是同一根杠杆（返回时间），需要的时间随实际偏离量增长；冻结比例顺带砍扰动量，
   峰值提前不砍。冻结比例在没有 arc 时不起作用。

**撤回过的（别再提）**：只扰抓取段；搬运段扰动超噪声就滑；鼓包太快不是太大；拉长自由段时间；抄平行
MimicGen 的实际位姿；追上目标就是推离源演示（对接触帧不成立）；2.10~2.13 里的三条（见汇总 §7）。

**术语（用户定）**：抓取段 = subtask 0/2；搬运段 = subtask 1/3；冻结段 = 每段末端冻结目标再靠近；
接近段 = 每段里靠近交互物体的部分。
